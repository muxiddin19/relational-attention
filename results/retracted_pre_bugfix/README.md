# Retracted: pre-bugfix ablation results

The files in this directory were produced **before** a config-forwarding bug was found and fixed in scripts/train.py's build_model() and scripts/evaluate.py's load_model(): the use_gating / use_mixing flags were defined in the training config but never threaded into the decoder block's model constructor, so any run that set these flags to ablate gating or mixing silently trained/evaluated with **both components fully active** regardless of the flag. The k4/k16 slot-count files here predate a similar set of corrections to how the model was reconstructed for evaluation and should not be trusted either.

We keep these files rather than deleting them, exactly as the paper does for every other retracted claim: not to use them, but so the record of what was wrong and why is not silently erased. The corrected re-runs, produced after both bugs were fixed, are the ones actually reported in the paper -- see the parent results/ directory and analysis/gsm8k_fixed_results/ for the corrected numbers.
