# Unverified results -- not cited in the paper

These files were found in the repository during a pre-submission audit but have **not** been through the same trace-to-config / verify-execution protocol applied to every number reported in the paper (see the paper's Mechanistic Analysis section for what that protocol looks like). Notably, eval_ffn2900_*.json appears to contain a real Standard-Transformer-with-matched-FFN-width run, which would be directly relevant to the paper's "Parameter Count Mismatch" limitation (currently stated as an unexecuted control) -- but we have not verified which config produced it, whether it completed a full training run, or why its predictions show heavy answer repetition, so we do not cite it. eval_rel_s45_a100 predates the hardware-claim correction (the paper's compute was 2x RTX 4090, not an A100) and its provenance needs the same check before use. Treat everything in this directory as an open follow-up item, not a result.
