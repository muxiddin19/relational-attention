# Paper files

The paper is prepared for submission to **Neurocomputing** (Elsevier).

| File | Description |
|---|---|
| `relattn_neurocomputing_submission.tex` | Main paper source (elsarticle format) |
| `relattn_neurocomputing_submission.pdf` | Compiled paper |
| `custom.bib` | Bibliography |
| `figures/` | The 6 figures used in the paper (architecture, theory visualization, results, ablations, mechanistic analysis) |
| `supplemental.tex` / `supplemental.pdf` | Supplementary material |

The experiment results underlying every table and figure are in `../results/`
(see `../results/README.md` for the file-to-table mapping) and
`../analysis/gsm8k_fixed_results/` (for the mechanistic-probing data).
